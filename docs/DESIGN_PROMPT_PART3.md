Продолжаем визуал «Робофермы» — **часть 3: графика для глав 2–7**. Уютный осенний стиль из второй части (рыжая земля, тёмные контуры, светотень, объём) уже утверждён — держи его в точности.

Игра уже написана и ждёт спрайты **с точными id из этого списка**. Пока их нет, в игре стоят заглушки. Как только id появятся в JSON, игра сразу их подхватит. Поэтому **названия id менять нельзя**.

## Формат (как раньше)

- Тот же самодостаточный HTML-файл и тот же JSON `#robofarm-assets`: та же схема, та же палитра. Новые цвета можно добавить, старые ключи не трогай.
- **Все прежние спрайты сохрани без изменений**, новые добавь. Валидатор на странице должен показывать «✓ ошибок нет».
- **Направления:** `_down`, `_up`, `_left`. Направление `_right` можно сделать зеркалом `_left` через `mirrorOf`.
- **Anchor** — точка, где объект стоит на земле.

## 4. Иконки (16×16)

- **Предметы:** `item_carrot`, `item_pumpkin`, `item_cabbage`, `item_apple`, `item_flour`, `item_sugar`, `item_box`.
- **Данные — «изнанка» мира, иконки должны быть очень понятными:**
  - `file_csv` — лист-таблица с сеткой;
  - `file_json` — лист с фигурными скобками `{ }`;
  - `file_txt` — лист с строчками;
  - `file_py` — свиток с кодом, без логотипа Python;
  - `file_image` — фото с горой;
  - `folder_closed`, `folder_open`.
- **Почта и лавка:**
  - `letter_closed`, `letter_open`, `parcel`, `receipt`;
  - `price_tag` 16×16 и `price_tag_big` 32×24 — деревянная табличка для текста на прилавке, с пустым светлым полем;
  - `coin_stack`.
- **Ярмарка и время:** `calendar`, `weather_sun`, `weather_rain`, `weather_cloud`, `medal_gold` (ярмарка).
