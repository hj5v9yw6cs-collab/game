Ты — арт-директор, пиксель-арт художник и UI-дизайнер игр. Спроектируй **весь визуальный контент** игры «Робоферма» **в одном самодостаточном HTML-файле**: арт-дирекцию, палитру, все спрайты и анимации, тайлы, интерфейс, макеты экранов, карту мира и иконку приложения.

Файл должен одновременно быть:
1. **Красивым стайлгайдом для человека.** Всё видно, анимации проигрываются, есть навигация по разделам.
2. **Точным источником данных для программиста.** Каждый пиксель каждого спрайта записан в файле как данные (формат ниже), и игра загрузит их напрямую. Ничего не рисуй «только картинкой»: всё, что видно на странице, должно рендериться из этих данных.

Стиль — **2D пиксель-арт уровня Stardew Valley**: тёплый, уютный, детальный, живой. Используй только **оригинальную графику** в похожем стиле. Не копируй ассеты Stardew Valley и других игр.

## 1. Об игре (контекст)

**«Робоферма»** — обучающая игра для macOS. Полный новичок учит настоящий Python, программируя команду робо-животных на бабушкиной ферме. Как *The Farmer Was Replaced*, но главное отличие — **«мир = данные»**: у каждого предмета есть «изнанка» из реальных данных. Грядки — таблица, очередь в лавке — список, касса — CSV-файл, заказы с сайта — JSON. Игрок видит, где этот код пригодится в жизни.

- **Сюжет.** Игроку (внук или внучка — выбирается в начале) достаётся заброшенная ферма «Осенний Лог». Бабушка Зина была инженером-изобретателем и оставила в сарае робо-животных и **робокурицу Клушу**, которая учит программировать. Цель — поднять ферму и победить на **Осенней ярмарке**.
- **Сезон и настроение:** уютная **осень**. Тыквы, яблоки, оранжевые и багровые клёны, опавшие листья, стога сена, туманные утра, тёплый свет «золотого часа».
- **Мир:** большая карта, вид сверху в перспективе 3/4 (как в Stardew Valley). Зоны открываются по сюжету, закрытые скрыты осенним туманом.
- **Интерфейс:** мир на весь экран, поверх него **пиксельные окна**, которые можно перетаскивать: окно скрипта робота (редактор кода), окно урока Клуши, «Память робота» и другие.
- **Обучение — главное в игре.** Интерфейс должен быть спокойным, ясным и читаемым. Код читается легко, ничего не мешает новичку. Красота не должна идти в ущерб понятности.
- **Режим «Рентген»:** мир превращается в «чертёж-синьку», и поверх объектов видны их данные.
- **Технически:** игра написана на Python + Qt. Она прочитает JSON из твоего файла и отрисует спрайты с целочисленным увеличением без сглаживания.
- **Язык интерфейса — русский.** Все надписи в макетах пиши по-русски, реальными текстами игры.

## 2. Арт-дирекция

### 2.1 Сетка и масштаб
- Базовый тайл — **16×16 px**. Все объекты стоят на сетке, размеры кратны 16 (исключения — мелкие иконки и эффекты).
- Люди — **16×32**. Роботы в мире — **16×16**, конь Искра — **32×32**.
- Деревья — 32×48 и 48×64. Здания — несколько тайлов (размеры в списке ассетов).
- Портреты для диалогов — **64×64**.
- В игре всё увеличено **×3** (настраивается ×2…×4), только целые множители, без сглаживания. Экран Mac 1440×900 при ×3 вмещает примерно 30×19 тайлов.
- Перспектива 3/4 сверху: у зданий видны крыша и фасад. Объекты сортируются по нижней точке (anchor) — у каждого спрайта она указана.

### 2.2 Палитра
- **Одна общая палитра на всю игру, 48–64 цвета**, собранная из цветовых «рамп» (переходов от тени к свету).
- Используй **hue shifting**: в светах оттенок уходит к тёплому жёлтому, в тенях — к фиолетово-синему.
- Обязательные рампы (названия цветов — латиницей, snake_case):
  - тёплый тёмный контур, **не чистый чёрный** (2–3 цвета);
  - трава: 5 ступеней, тёплый оливково-зелёный, осенний;
  - осенняя листва: оранжевая (5), багрово-красная (4), жёлто-охристая (4);
  - земля сухая (3) и влажная/политая (3);
  - дерево построек (4), солома и сено (3), камень (4);
  - вода (4);
  - медь и латунь (4), сталь холодная серо-синяя (4), белая эмаль (3) — материалы роботов;
  - кожа людей (3 тона по 3 ступени);
  - туман и небо: лавандово-серые (3);
  - интерфейс: пергамент (3), рамки из тёмного дерева (4), фон редактора кода (2), успех-зелёный (2), ошибка-красный (2), предупреждение-янтарный (2), монеты-золото (3);
  - рентген: глубокая «синька» (2), циан для линий и текста (2);
  - полупрозрачные: тень под объектами (чёрно-фиолетовая, альфа около 35%), затемнение под модальными окнами.
- Каждый цвет в данных получает **ключ — один символ** (`0-9`, `a-z`, `A-Z`, при нехватке — `!#$%&*+-=?@^~`). Символ `.` — всегда прозрачный пиксель.

### 2.3 Свет, тени, контуры
- Свет всегда **сверху-слева**, тёплый. Тени снизу-справа, холодные.
- Контуры **цветные** (самый тёмный оттенок своей рампы), на освещённой стороне можно частично убирать контур (selective outline), как в Stardew Valley.
- Без градиентов и без полупрозрачности внутри спрайтов (полупрозрачность — только у теней, эффектов и UI-оверлеев). Минимум дизеринга, никаких «одиночных шумных» пикселей.
- Под каждым персонажем и роботом — отдельный спрайт тени-овала (`shadow_s`, `shadow_m`, `shadow_l`).
- **Ховер-подсветка** любого объекта мира: контур в 1 px светлым цветом. Опиши правило и покажи пример.

### 2.4 Характер и детализация
- Роботы — **ретро-инженерия бабушки**: медь, латунь, белая эмаль, заклёпки, лампочки вместо глаз, пружинки и антенны. Милые, с характером, читаются силуэтом даже в 16×16. У каждого робота свой цвет-акцент, чтобы их было легко различить.
- Люди — добрые, немного карикатурные деревенские персонажи.
- Мир живой: колышется трава, падают листья, идёт дым из трубы, крутится ветряк, на воде бликуют искорки.

## 3. Формат файла (строго обязательно)

### 3.1 Общие правила
- **Один HTML-файл**, полностью самодостаточный: без внешних картинок. Внешними могут быть только шрифты (Google Fonts или аналог с открытой лицензией).
- Все данные лежат **в одном JSON** внутри тега:
  `<script type="application/json" id="robofarm-assets"> … </script>`
- Страница рисует **всё** (спрайты, анимации, макеты, карту) из этого JSON через `<canvas>` с `imageSmoothingEnabled = false`.
- Идентификаторы — латиница, `snake_case`, уникальные.
- Направленные анимации — суффиксы `_down`, `_up`, `_left`, `_right`. Анимацию `_right` можно не рисовать, а объявить зеркалом `_left` (поле `mirrorOf`).

Результат вверху страницы: «Проверка данных: ✓ ошибок нет» или список ошибок.
5. **Манифест**: таблица всех id с группой, размером и числом кадров.
6. **Кнопки экспорта**: «Скачать JSON» и «Скачать PNG-атлас» (все спрайты на одном листе + JSON с координатами).

## 4. Полный список ассетов

Для каждого пункта — размер, кадры и примерная длительность кадра. Если пишешь «4 dirs × 4» — это 4 направления по 4 кадра (`_right` можно сделать зеркалом).

### 4.1 Земля, вода, ограды (16×16)
- Трава: 4 базовые вариации, 3 с опавшими листьями, 2 с осенними цветами (астры, бархатцы), высокая трава (декор, 2 кадра колыхания, 400 мс).
- Тропинка из утоптанной земли — автотайл (13 тайлов: центр, 4 стороны, 4 внешних угла, 4 внутренних).
- Булыжная дорога в город — автотайл (13 тайлов).
- Вспаханная грядка: сухая, политая (тёмная, влажная), пересохшая с трещинами, заросшая сорняком. Грядки должны бесшовно стыковаться рядами.
- Вода (пруд) — автотайл (13 тайлов), центр анимирован бликами (3 кадра, 300 мс).
- Деревянный мостик (горизонтальный и вертикальный, по 3 тайла).
- Забор: горизонтальный, вертикальный, 4 угла, столбик, калитка (закрыта и открыта).
- Туман закрытых зон: тайл облака (полупрозрачный, медленный дрейф — 4 кадра, 600 мс) + край тумана (4 стороны и 4 угла).
- Курсор выбранной клетки 16×16 (2 кадра мигания, 500 мс).

### 4.2 Растения (стадии роста, по 16×16, высокие — 16×32)
Для каждой культуры: **семя в лунке → росток → растёт → почти готово → спелое → увядшее**.
- Морковь, тыква (спелая — крупная оранжевая, может выходить за тайл: укажи anchor), капуста (главы 1–2).
- Свёкла, картофель, кукуруза (16×32), подсолнух (16×32) — для поздних глав.
- **Яблоня** 32×48: без плодов, с зелёными яблоками, со спелыми красными, после сбора. Плюс отдельный спрайт упавшего яблока.
- Отдельные оверлеи состояния грядки: «нужен полив» (капля), «спелое» (искорка) — 8×8, по 2 кадра.

### 4.3 Деревья и природный декор
- Клён оранжевый, клён багровый, берёза жёлтая (32×48), большая ель (32×64), дуб (48×64). У каждого дерева — лёгкое покачивание кроны (2 кадра, 600 мс) и пень после вырубки.
- Кусты (16×16 и 32×16, 2 вариации), шиповник с ягодами, грибы (2 вида), камни (3 размера), брёвна, коряга.
- Декоративные тыквы (3 размера), стог сена (32×32), снопы пшеницы, кучи листьев (2 размера).

### 4.4 Постройки
У каждой постройки две версии: **заброшенная** (доски, дыры, паутина, мох) и **отремонтированная**. Ремонт — визуальная награда игроку.
- **Дом бабушки** — 7×6 тайлов. Резные наличники, крыльцо, труба с дымом, мансарда-контора. Окна в двух вариантах: тёмные и светятся.
- **Сарай-мастерская** (стартовая точка, здесь просыпается Клуша) — 5×4. Вывеска «Мастерская», приоткрытая дверь (закрыта и открыта).
- **Амбар** — 7×6, классический красный, большие ворота (закрыты и открыты).
- **Лавка у дороги** — 5×3. Прилавок с полосатым навесом, ящики с овощами, касса, вывеска «Лавка „Осенний Лог“». Ставни открыты и закрыты.
- **Почта** — 5×4, синяя вывеска «Почта», почтовый ящик рядом (флажок поднят и опущен).
- **Бабушкин ветряк-электростанция** — 3×5, лопасти крутятся (4 кадра, 150 мс).
- **Ярмарка**: большой шатёр (6×5), 2 вида прилавков (3×2), гирлянда флажков (повторяемая), арка входа «Осенняя ярмарка».
- Колодец (2×2), доска объявлений с заданиями (2×2, с листочками и без), указатели «Город →», «Поле», «Амбар».

### 4.5 Предметы и декор фермы (16×16, если не указано иное)
Бочка, ящики (пустой, с морковью, с тыквами, с яблоками), мешок семян, тачка (32×16), лейка на земле, корзина (пустая и полная), фонарь (горит и не горит, 2 кадра мерцания), скамейка (32×16), почтовый ящик фермы, **датчик влажности** — колышек со шкалой (3 состояния: сухо / норма / мокро), пугало-декор (16×32), верстак (32×16).

### 4.6 Роботы
У каждого робота — спрайты в мире, иконка 16×16 для интерфейса (голова), портрет 64×64 с эмоциями. Все роботы — из меди, латуни, эмали и заклёпок, с лампочками-глазами.

**🐔 Клуша — робокурица-наставник** (16×16, портрет 64×64)
- Вид: белая эмаль с парой вмятин и заклёпками, медный клюв, гребешок из трёх красных лампочек (горят, когда говорит), **маленькие круглые очки**, лючок с винтиком на боку, хвост из медных пластин.
- Характер: ворчливая, заботливая, гордая, с юмором.
- Анимации: выключена (серая, 1 кадр), включение (4 кадра: лампочки загораются, искра), idle (2 кадра, 500 мс), ходьба (4 dirs × 4, 125 мс), говорит (3 кадра: клюв и гребешок), указывает крылом (2 кадра — для уроков), радуется (подпрыгивает, 4 кадра), хмурится из-за ошибки (3 кадра), думает (2 кадра + «?» над головой), клюёт (3 кадра).
- Портрет, 8 эмоций: спокойная, объясняет (крыло поднято), радуется, хмурится, удивлена, гордится, думает, сонная.

**🐕 Бублик — робопёс, поле** (16×16)
- Вид: рыжая медь, висячие уши на пружинках, хвост-антенна с лампочкой, **бак-лейка с краником на спине**, синие лампочки-глаза. Добрый и суетливый.
- Анимации: idle (2), ходьба (4 dirs × 4), полив (4 кадра; струю воды сделай отдельным эффектом), сбор урожая (4: тянет и кладёт в корзину на спине), ходьба с полной корзиной (4 dirs × 4), сканирует грядку датчиком (4 кадра, луч), радость — виляет хвостом (4), растерян (2 + «?»), сон (2 + «zZ»).

**🐈 Мурзик — робокот, лавка** (16×16)
- Вид: серо-стальной корпус в полоску из пластин, зелёные лампочки-глаза, усы-проволочки, **маленький экран-касса на груди**, хвост — кабель с вилкой.

## 5. Интерфейс (UI-кит)

Все окна **полностью пиксельные**, в духе Stardew Valley: **рамка из тёмного дерева, контент на пергаменте**. Исключение — область кода: она **тёмная**, как «грифельная доска» или старый терминал внутри деревянной рамки. Так код читается легче, а потом игроку будет привычно в настоящих редакторах.

### 5.1 Шрифты
- **UI-шрифт:** пиксельный, с **полной кириллицей** (проверь Ё ё Щ щ Ъ ъ Ы ы Э э Ю ю Я я), открытая лицензия (OFL или аналог, чтобы можно было встроить в приложение). Два размера плюс вариант для заголовков.
- **Шрифт кода:** **моноширинный** пиксельный, кириллица и латиница. Обязательно различимы: ноль, латинская O и русская о (0 O о); единица, l, I и черта (1 l I |); одинарная, двойная и обратная кавычки (' " `); скобки ( [ {; двоеточие и точка с запятой (: ;); дефис, подчёркивание и тильда (- _ ~); точка и запятая (. ,). Хорошо читается при ×2 на Retina.
- **Шрифт заголовков и логотипа:** декоративный пиксельный, тоже с кириллицей.
- Для каждого шрифта укажи название, ссылку, лицензию и размеры. Покажи образцы:
  - фраза: «Съешь же ещё этих мягких французских булок, да выпей чаю»;
  - строка: `for грядка in поле: полить(грядка)  # 0O о 1lI`;
  - числа: `{"влажность": 23}`.
- Если готового подходящего шрифта нет — нарисуй свой как данные (`glyphs`).

### 5.2 Цвета подсветки кода
Задай цвета для тёмного фона редактора. Контраст текста к фону — **не меньше 4.5:1**.
- **Цвета токенов:**
  - ключевые слова (`for`, `in`, `if`, `else`, `def`, `return`, `import`);
  - встроенные функции (`print`, `len`, `range`, `int`, `str`);
  - **команды роботов** (`полить`, `собрать`, `water`, `harvest`) — отдельный заметный цвет: «это руки робота»;
  - вызов функции, строки, числа, комментарии, операторы, скобки.
- **Цвета редактора:** номера строк и поле слева, текущая строка, строка с ошибкой, выделение.
- **Специальные состояния:**
  - пропуск `____` в шаге «Допиши»;
  - **подозрительный символ** — кириллическая буква внутри латинского слова (например, русская «р» в `print`), частая ошибка новичков.

### 5.3 Базовые компоненты (каждый — со всеми состояниями: обычное, наведение, нажато, отключено, фокус)
- **Рамка окна** (9-slice): деревянная, с осенним листиком-орнаментом в углу.
  - Заголовок: слот иконки 16×16, текст, кнопки «свернуть» и «закрыть».
  - Уголок изменения размера, тень окна.
  - Варианты контента: пергамент и тёмный (для кода).
- **Панели:** вдавленная панель, разделитель.
- **Кнопки:** основная («Пуск» — зелёная), обычная (деревянная), опасная («Стоп» — красная), кнопка-иконка. Размеры S и M.
- **Переключатели:** вкладки, ползунок скорости с черепахой и зайцем на концах, полоса прокрутки, чекбокс (цели задания), радиокнопка, тумблер.
- **Ввод и прогресс:** поле ввода текста (имя игрока), прогресс урока (точки шагов «шаг 2 из 6»), счётчик монет.
- **Всплывающие элементы:** тултип, тост-уведомление, затемнение под модальным окном.
- **Таблица в стиле амбарной книги** (просмотр CSV): заголовок, строки «зеброй», подсветка новой или изменённой строки.
- **Дерево JSON:** раскрывающиеся узлы, ключи и значения разными цветами.

### 5.4 Окна игры — нарисуй каждое отдельно со всеми состояниями

1. **Окно скрипта робота.** Заголовок: иконка робота и имя файла `бублик.py`.

   - **Шаг «Допиши»:** мигающий слот-пропуск.
   - **Подсказка-перевод** при наведении на `for` («для каждого»), `in` («в»), `if` («если»), `print` («напечатать»).
   - **Панель:** Пуск, Пауза, Шаг, Стоп, ползунок скорости, «Подсказка».
   - **Строка статуса:** «Готов к запуску», «Выполняю строку 3», «Ошибка в строке 2», «Готово ✓».

2. **Окно урока Клуши.**

   - `None` — пустой ящик с паутинкой;

   - Анимации: значение изменилось (вспышка, 3 кадра); новая переменная появилась (pop).
   - Внизу строка: «→ строка 2: проверяю условие».

7. **«Задание выполнено!»** Конфетти, награда «+120 🪙», кнопки «Разбор решения», «В жизни», «Дальше».
8. **Разбор решения.** Слева код, справа пояснение к каждой строке со стрелками-выносками, блок «Можно было ещё так».
9. **Карточка «В жизни»** — в стиле газетной вырезки или открытки. Иконки примеров из жизни, блок «Попробуй у себя» с шагами, кнопка «Открыть в Finder».

## 7. Карта мира

Собери карту **80×50 тайлов** в разделе `map` (формат в п. 3.2). Слои: земля (символы по легенде), объекты (список спрайтов с координатами), зоны (прямоугольники с порядком открытия). Примерная планировка:

```
┌──────────────────────────────────────────────────────────────┐
│  лес (клёны, ели)     ДОРОГА В ГОРОД ═══════════════════► →   │
│        ┌──────┐                         ┌────────┐   ПОЧТА   │
│  САД   │ ДОМ  │   САРАЙ (старт)         │ АМБАР  │           │
│ яблони └──────┘   + огород 3 грядки     └────────┘           │
│              ПОЛЕ (много грядок)               ЛАВКА у дороги │
│     пруд                                       очередь        │
│  ветряк                          ЯРМАРКА (финал)             │
└──────────────────────────────────────────────────────────────┘
```

**Порядок зон:** 1) Сарай и огород → 2) Поле → 3) Лавка → 4) Амбар → 5) Почта и дорога → 6) Дом-контора и сад → 7) Ярмарка.

**Требования:**
- Тропинки соединяют все зоны, вокруг фермы — забор.
- Пруд с мостиком, ветряк, много осеннего декора по краям: деревья, кусты, листья, грибы, тыквы, стога.
- В начале игры всё, кроме зоны 1, закрыто туманом и выглядит заброшенным.

Покажи карту на странице целиком (с прокруткой и масштабом) и с переключателем «начало игры / всё открыто и отремонтировано».

## 9. Порядок работы и приоритеты
