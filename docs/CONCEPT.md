# Робоферма — концепция игры

> Игра для Mac, в которой ты учишь настоящий Python, управляя командой робо-животных на бабушкиной ферме.
> Как **The Farmer Was Replaced**, но с одним главным отличием: каждая строчка кода сразу показывает, **где она пригодится в жизни**.

*Рабочее название — «Робоферма». Его можно поменять.*

---

## 1. Идея в одном абзаце

Тебе достаётся в наследство заброшенная бабушкина ферма. Бабушка была инженером-изобретателем: в сарае ждут её робо-животные и **робокурица Клуша**, которая знает Python и учит тебя программировать. Ты пишешь программы для роботов. Они поливают поле, торгуют в лавке, ведут склад, развозят заказы и считают деньги. Главная фишка — **«мир = данные»**. Грядки — это таблица, очередь в лавке — список, касса — CSV-файл, заказы с сайта — JSON. Всё это лежит **настоящими файлами на твоём Mac**, и тот же самый код работает с твоими собственными данными: выпиской из банка, фотографиями, таблицами с работы.

## 3. Сюжет

**Завязка.** Приходит письмо: «Ферма „Осенний Лог“ теперь твоя. В сарае тебя ждут. Бабушка». Ферма заросла, урожай гибнет, до **Осенней ярмарки** — один сезон. В сарае включается Клуша: «Ко-ко! Наконец-то! Фермер из тебя, прости, никакой. Зато роботы слушаются того, кто умеет писать программы. Научу».

В начале игры выбираешь, кто ты: **внук** или **внучка**. От этого зависят обращения в диалогах.

**Цель.** Поднять ферму, открыть лавку, наладить доставку в город и победить на Осенней ярмарке как самая умная ферма в области.

**Соседи дают задания** (это «заказчики», как на настоящей работе):

| Персонаж | Кто это | Какие задачи приносит |
|---|---|---|
| **Дед Михалыч** | Сосед-фермер, роботам не доверяет | Поле: полив, урожай, «а ну посчитай, сколько собрали» |
| **Тётя Валя** | Хозяйка сельского магазина | Лавка: цены, чеки, скидки |
| **Почтальонка Даша** | Возит почту и заказы из города | Заказы с сайта, доставка, сроки |
| **Петя** | Школьник, ведёт соцсети фермы | Фото урожая, папки, переименование файлов |
| **Инспектор Сидоров** | Строгий налоговый инспектор | Отчёты, таблицы для Excel и Numbers |

## 4. Команда роботов

Роботы появляются по одному. Каждый новый робот — это новая глава, новая зона и новые темы Python.

| Робот | Где работает | Что делает | Чему учит |
|---|---|---|---|
| 🐔 **Клуша** (робокурица) | Везде | Наставник: ведёт уроки, объясняет ошибки, подсказывает | — |
| 🐕 **Бублик** (робопёс) | Поле | Поливает, собирает урожай, следит за датчиками | Команды, переменные, списки, циклы, условия |
| 🐈 **Мурзик** (робокот) | Лавка | Обслуживает очередь, считает чеки, печатает ценники | Строки, f-строки, словари, функции |
| 🦫 **Бобр** (робобобр) | Амбар | Ведёт склад, раскладывает товар, заказывает поставки | Файлы, CSV, ошибки в данных (try/except) |
| 🐎 **Искра** (робоконь) | Почта и дорога в город | Развозит заказы с сайта по маршруту | JSON, вложенные данные, сортировка, даты |
| 🦉 **Ухта** (робосова) | Контора | Отчёты, фото, папки, анализ продаж | Папки и файлы, отчёты, несколько файлов сразу |

## 5. Мир

Большая пиксельная карта (вид сверху, как в Stardew Valley). Камера двигается мышкой или стрелками, есть приближение. Закрытые зоны скрыты осенним туманом и открываются по сюжету.

```
┌──────────────────────────────────────────────────────────────┐
│  🌲🍂🌲      ДОРОГА В ГОРОД  ════════════════════════► 🏘     │
│        ┌──────┐                         ┌────────┐   📮     │
│  🍎🍎  │ДОМ   │   🏚 САРАЙ              │ АМБАР  │  ПОЧТА  │
│  🍎САД │контора│  (старт, Клуша)        │  🦫    │  🐎     │
│  🍎🍎  └──────┘                         └────────┘         │
│              🎃🎃🎃🥕🥕🥕🥬🥬               🏪 ЛАВКА         │
│              🎃🎃🎃🥕🥕🥕🥬🥬   ← ПОЛЕ      🐈 🧑🧑🧑 очередь │
│                   🐕                                       │
│  🍂 туман 🍂 туман 🍂            ЯРМАРКА (финал) 🎪        │
└──────────────────────────────────────────────────────────────┘
```

Зоны по порядку: **Сарай и огород** (3 грядки) → **Поле** → **Лавка** → **Амбар** → **Почта и дорога** → **Контора и сад** → **Ярмарка**.

### «Мир = данные»: у каждого предмета есть изнанка

| В мире | В коде | Настоящий файл на Mac |
|---|---|---|
| Грядки на поле | список словарей `поле` | `Робоферма/поле/грядки.csv` |
| Датчик влажности на грядке | `грядка["влажность"]` | столбец в той же таблице |
| Очередь в лавке | список `queue` | — |
| Касса | строки журнала продаж | `Робоферма/лавка/sales.csv` |
| Ящики в амбаре | словарь `stock` | `Робоферма/амбар/stock.json` |
| Почтовый ящик с заказами | `orders = json.load(...)` | `Робоферма/почта/orders.json` |
| Фотоаппарат Пети | файлы в папке | `Робоферма/фото/*.png` (настоящие картинки) |
| Прогноз погоды | словарь из JSON | `Робоферма/погода/forecast.json` (формат настоящего погодного сайта) |

**Режим «Рентген»** (клавиша `R` или кнопка 🔍). Мир тускнеет, и поверх предметов появляются их данные: над грядками словари, над очередью список, над кассой последние строки таблицы. Нажимаешь на подпись — открывается файл.

```
ОБЫЧНЫЙ ВИД                    РЕНТГЕН
 🎃   🎃   🥕                   {"культура": "тыква",
                                 "влажность": 23,
                                 "спелая": True}
 🧑🧑🧑 → 🏪🐈                    queue = ["Михалыч", "Валя", "Петя"]
```

**Карточка при наведении.** Наводишь мышку на грядку, и всплывает пиксельная карточка: что это, какие у предмета данные, как до них добраться в коде (`поле[2]["влажность"]`) и в каком файле они лежат.

Мир на весь экран, поверх него пиксельные окна (как в TFWR): их можно двигать, сворачивать и открывать несколько сразу.

```

│  ║                           ║   ╔═ 🧠 Память Бублика ═══╗         │
```

- **Верхняя панель:** монеты, игровой день, текущая глава. Кнопки: 🔍 Рентген, 📒 Блокнот Клуши (шпаргалка), 🗺 Задания, ⚙ Настройки (размер шрифта и прочее).
- **Окно скрипта робота** — у каждого робота своё. Клик по роботу в мире открывает его окно.
- **Окно Клуши** — уроки, подсказки, объяснения ошибок.
- **Память робота** — что сейчас лежит в переменных.

## 7. Обучение — самое важное

### 7.1 Принципы

1. **Одна новая идея за раз.** В каждом шаге урока — одна мысль и не больше 2–3 коротких предложений.
2. **Сначала «зачем», потом «как».** Каждая тема начинается с проблемы на ферме: «грядок стало 30 — писать 30 строк?» Потом решение: цикл.
3. **Увидел → повторил → сделал сам.** Сначала Клуша показывает пример, потом ты дописываешь пропуск, потом пишешь сам.
4. **Проверка сразу.** Каждый шаг проверяется мгновенно, нельзя «уехать» с непонятой темой.
5. **Ошибка — это нормально.** Клуша объясняет её человеческим языком и показывает строку. Никаких штрафов.
6. **Связь с жизнью в каждом уроке.** После каждой задачи — карточка «В жизни» с конкретными примерами.
7. **Повторение.** Старые темы возвращаются в новых задачах: циклы из главы 2 нужны в лавке, амбаре и на почте.
8. **Деньги не мешают учиться.** Подсказки, уроки и шпаргалка всегда бесплатные. За монеты — только улучшения фермы.

### 7.2 Цикл одной темы

```
 ① УРОК с Клушей  →  ② ЗАДАНИЕ на ферме  →  ③ РАЗБОР  →  ④ «В ЖИЗНИ»  →  ⑤ АВТОМАТИЗАЦИЯ
   4–7 маленьких      робот делает            каждая        где это           скрипт работает
   шагов              настоящую работу        строчка       применить,        каждый игровой день
                      соседу                  объяснена     «попробуй у себя» и приносит монеты
```

### 7.3 Типы шагов в уроке

| Шаг | Что происходит |
|---|---|
| 👀 **Смотри** | Клуша объясняет на аналогии («переменная — ящик с наклейкой»), в мире идёт анимация |
| ▶ **Запусти** | Готовый пример: жмёшь «Пуск» и смотришь пошагово, как робот выполняет каждую строку |
| ✏ **Допиши** | В коде пропуск `____`, вписываешь 1–2 слова или строчку |
| 🔧 **Исправь** | В коде ошибка, найди и исправь. Клуша показывает, как выглядит такая ошибка в настоящем Python |
| 🧩 **Напиши сам** | Маленькая самостоятельная задача на 2–4 строки |

### 7.4 Пример полного урока: «Цикл for» (глава 2)

> **Шаг 1 — 👀 Смотри.**
> 🐔 «Ко-ко! Вчера мы поливали каждую грядку отдельной командой. Пять грядок — пять одинаковых строк. А Михалыч отдал нам ещё поле на 30 грядок. Будем писать 30 строк?»
> *В мире: Бублик бегает к каждой грядке, сбоку растёт столбик одинаковых строк `полить(...)`.*
>
> **Шаг 2 — 👀 Смотри.**
> 🐔 «Цикл `for` — это „для каждого“. Читай вслух: **для каждой грядки в поле — полей её**».
> ```python
> for грядка in поле:
>     полить(грядка)
> ```
> *При наведении: `for` — «для каждого», `in` — «в».*
>
> **Шаг 3 — ▶ Запусти.** Жмёшь «Шаг» несколько раз. На каждом круге ящик `грядка` в «Памяти Бублика» меняется (грядка 1 → грядка 2 → …), а Бублик бежит к следующей грядке.
>
> **Шаг 4 — 👀 Смотри: отступ.**
> 🐔 «Видишь 4 пробела перед `полить`? Это **отступ**. Всё, что с отступом, повторяется для каждой грядки. Без отступа выполнится один раз, уже после цикла».
> ```python
> for грядка in поле:
>     полить(грядка)      # повторяется
> print("Готово!")        # один раз в конце
> ```
>
> **Шаг 5 — ✏ Допиши.** Теперь собери урожай с каждой грядки:
> ```python
> for грядка in поле:
>     ________
> ```
> Если написано `собрать` без скобок, Клуша скажет: «Почти! Чтобы робот выполнил команду, после имени нужны скобки: `собрать(грядка)`».
>
> **Шаг 6 — 🔧 Исправь.** В коде две ошибки: нет двоеточия и нет отступа.
> ```python
> for грядка in поле
> полить(грядка)
> ```
>
> **ЗАДАНИЕ от Михалыча.** «Полей всё поле и скажи, сколько там грядок». Нужны цикл и счётчик, а счётчик уже был в теме «Переменные» — это повторение.
>
> **РАЗБОР.** Каждая строчка решения подписана простыми словами плюс «можно было ещё так».
>
> **В ЖИЗНИ.** «`for` — это „сделай для каждого“: для каждого письма в почте, каждого файла в папке, каждой строки в таблице. Так рассылают поздравления сотне клиентов, переименовывают тысячу фото, проверяют каждую покупку в выписке банка».

### 7.5 Инструменты, которые помогают понять код

- **Пошаговый запуск.** Текущая строка подсвечивается, робот в мире делает действие в тот же момент. Кнопки: ▶ Пуск, ⏸ Пауза, ⏭ Шаг, ползунок скорости 🐢—🐇.
- **Память робота.** Каждая переменная нарисована пиксельным ящиком с наклейкой-именем. Список — ряд ящиков с номерами 0, 1, 2…, словарь — ящик с подписанными отделениями. Изменившееся значение мигает.
- **Разбор решения.** После задачи каждая строка твоего кода и эталонного решения объясняется по-русски.
- **Подсказки в 3 уровня:** 1) куда смотреть; 2) какая конструкция нужна; 3) почти готовый код. Готовое решение открывается после нескольких попыток, но и оно идёт с объяснением.
- **Ошибки по-русски.** Строка с ошибкой подсвечивается красным, а Клуша объясняет:
  > 🐔 «Строка 1: после `for грядка in поле` не хватает двоеточия `:`. Двоеточие говорит Python: „дальше идут команды, которые надо повторять“».
  > *Свернуто: «Как это выглядит в настоящем Python» с оригинальным `SyntaxError`, чтобы потом не пугаться.*
- **Умные проверки опечаток.** «Python не знает слова `полит`. Может, ты имел в виду `полить`?»
- **Переводчик при наведении.** Наводишь на `for`, `if`, `print`, `return` — видишь перевод и смысл.
- **Блокнот Клуши.** Шпаргалка по всем пройденным темам с примерами. Можно открыть в любой момент.

### 7.6 Русские названия → английские

- **Главы 1–2:** `поле`, `грядка`, `полить(грядка)`, `урожай = 0`. Python разрешает русские имена, так новичку проще сосредоточиться на смысле. Ключевые слова Python (`for`, `if`, `print`) остаются английскими, у них есть перевод при наведении.
- **Начало главы 3 — отдельный урок:** «Почему программисты пишут по-английски». Так код поймут во всём мире, библиотеки (`csv`, `json`) уже на английском, в настоящей работе пишут так же. Дальше имена английские: `water(bed)`, `price`, `orders`. Старые русские команды продолжают работать, чтобы ничего не ломалось.
- **Данные остаются русскими:** «тыква», «Михалыч», «ул. Садовая».

## 9. Мост в реальную жизнь

1. **Настоящая папка на Mac.** При первом запуске создаётся `~/Documents/Робоферма/` со всеми данными фермы и скриптами роботов. Кнопка **«Открыть в Finder»** — и вот они, те самые CSV и JSON. Их можно открыть в Numbers или Excel.
2. **Настоящий Python.** Код игрока выполняет настоящий Python, а не эмуляция. Скрипт робота — обычный `.py` файл.
3. **Карточка «В жизни»** после каждой задачи: 2–3 конкретных примера из жизни и работы.
4. **«Попробуй у себя».** Пошаговая инструкция: открыть Терминал, запустить скрипт командой `python3`, подложить свои данные. С 4-й главы роботам не нужны игровые команды: скрипт работает только с файлами, а значит, работает и вне игры.
5. **Финал «Что дальше».** Подборка идей, как применить навыки к своей жизни, и примеры: траты по выписке из банка, сортировка фото, настоящий прогноз погоды с сайта.

## 10. Монеты и прогресс

- **Монеты 🪙** дают за выполненные задания. Каждый готовый скрипт **работает сам каждый игровой день** (день — пара минут реального времени): поле поливается, лавка торгует, заказы развозятся. Это приносит пассивный доход, как в TFWR.
- **На монеты покупаются:** новые грядки и семена (морковь → тыква → яблони…), постройки в зонах, ускорение роботов, украшения фермы.
- **Сюжет не требует «фармить».** Наград за задания хватает, чтобы идти дальше. Монеты нужны для удовольствия и красоты фермы.

## 11. Технически (кратко)

- **Язык и библиотеки:** Python 3 + **PySide6 (Qt)**. Игра сама написана на Python — тоже пример того, что можно сделать на этом языке.
- **Графика:** пиксельные спрайты рисуются кодом (палитра + «картинка из символов»), увеличиваются без размытия. Пиксельный шрифт с кириллицей, размер настраивается.
- **Запуск кода игрока:** отдельный процесс настоящего Python. Записывается каждый шаг (строка, значения переменных, действия робота), потом игра проигрывает это анимацией. Защита от бесконечных циклов и зависаний.
- **Данные фермы:** `~/Documents/Робоферма/`. **Сохранения:** `~/Library/Application Support/Робоферма/`.
- **Запуск на Mac — два способа:**
  1. Готовое приложение: GitHub сам собирает `Робоферма.app` на своём Mac-сервере, ты скачиваешь и переносишь в «Программы». Приложение без платной подписи Apple, поэтому первый раз открывается через «Правый клик → Открыть».
  2. Из Терминала: `pip3 install -r requirements.txt`, затем `python3 main.py`.
- **Тесты:** каждый урок автоматически проверяется — эталонное решение проходит, типичные ошибки дают правильные подсказки.
